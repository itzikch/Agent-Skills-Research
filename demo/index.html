STAGE 01 / SECURITY BOUNDARY

Define what can become executable

Definition locked

Natural-language instructions can become file reads, processes, network calls, and durable changes. The skill’s Markdown therefore belongs inside the security boundary.

Agentic skill

Behavior packaged as instructions

A versionable bundle of model-readable instructions plus optional scripts, references, assets, and tool requirements that changes how an agent completes a task.

Malicious skill

Purpose and behavior no longer agree

A skill whose intended or foreseeable behavior covertly violates authorization, confidentiality, integrity, availability, or the controls protecting them.

STAGE 07 / CLAIM BOUNDARY

What the detectors cannot see

Benign ≠ safe

Static and runtime evidence overlap, but neither proves intent. A patient attacker can stay inside individually legitimate operations, spread behavior across sessions, or reuse approved destinations.

Static misses

  • Remote instructions fetched later
  • Novel encodings or encrypted payloads
  • Dynamic paths and runtime arguments
  • Compromised dependencies after review

Runtime misses

  • Behavior outside the correlation window
  • Legitimate-looking approved destinations
  • Incorrect sensitive-data labels
  • Agent-controlled or incomplete logs

Both can miss

  • Low-and-slow cross-session behavior
  • Abuse split across cooperating skills
  • Semantic leakage through normal tools
  • Clean review followed by update drift

STAGE 08 / INTERVIEW HANDOFF

Close with the process, not the score

Reproducible

Boundary: I treat natural-language skill instructions as security-sensitive because the model can translate them into tool calls.

Baseline: Ten pinned public skills measure false positives; the final scanner keeps all ten Benign.

Attacks: Three inert fixtures test direct exfiltration, durable skill shadowing, and representation evasion.

Failure: V1 missed base64. V2 added bounded decoded-layer inspection and caught the class without a file-specific signature.

Runtime: Session-aware correlations complement static analysis, but the lab safely replays telemetry rather than executing malware.

Honesty: Antigravity discovery and Ollama instruction following passed; OpenClaw remained untested because policy blocked installation.

Limit: A Benign result means no configured correlation crossed threshold. Provenance, least privilege, isolation, and runtime policy remain necessary.
