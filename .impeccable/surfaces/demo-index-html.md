# Agentic Skills / Security Proof

## Thesis

Security claims become credible when every claim stays attached to its evidence. This surface rejects the generic metric-card security dashboard in favor of an inspectable technical artifact.

## Own-world hook

A print-production proof sheet: warm paper, registration cyan, verification green, warning orange, crop marks, measurement rules, ledgers, and stamped states.

## Story and first viewport

The first viewport establishes the artifact, top-line outcomes, and the complete seven-stage route. A narrow stage rail remains beside one large evidence field as the presenter moves from definition through benign control, attacks, V1 failure, V2 improvement, runtime correlation, platform validation, and limits.

## Interaction

Stage buttons, previous/next controls, and left/right keyboard shortcuts move through the trace. The attack panel provides keyboard-operable technique tabs; the scanner comparison toggles literal and decoded inspection layers; the runtime panel replays declared correlations. These interactions explain evidence and never imply malicious execution.

## Responsive and accessibility

At 940px the rail becomes a horizontal stage strip and comparison layouts stack. At 600px evidence pairs become single columns, event arrows rotate, and low-priority table detail hides. The surface includes a skip link, visible focus, semantic states, live announcements, reduced-motion behavior, and a print view that expands all seven stages.

## Evidence boundary

The surface must distinguish static findings, simulated runtime telemetry, observed platform behavior, and unvalidated claims. The malicious fixtures remain inert. Antigravity discovery and Ollama instruction-following results are observed; OpenClaw execution is not claimed because policy blocked installation.
